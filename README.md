# Website Funnel Analysis | SQL & Power BI

## Project Overview
An end-to-end data analysis project focused on understanding customer behaviour, conversion rates, user drop-offs, and revenue performance using SQL and Power BI.

## Tools & Technologies
- SQL
- Microsoft Power BI
- DAX
- Power Query
- CSV Dataset

## Key Analysis
- Customer conversion funnel analysis
- User drop-off analysis
- Revenue by marketing channel and region
- Device-wise revenue and conversion analysis
- Product category performance

## Key Insights
- Total Users: 10,000
- Total Revenue: 277,323.06
- Total Purchases: 1,004
- Overall Conversion Rate: 10.04%
- Highest Revenue Channel: Google Ads
- Highest Revenue Region: South
- Highest Revenue Product Category: Electronics
- Largest Percentage Drop-off: Checkout to Purchase (70.95%)

## Business Recommendations
- Simplify the checkout process.
- Improve mobile shopping experience.
- Optimize marketing campaigns.
- Strengthen regional and product category strategies.

## Project Structure
- `SQL/` – SQL queries and analysis
- `PowerBI/` – Power BI dashboard file
- `Dataset/` – Source dataset
- `Report/` – Final project report

## Conclusion
This project demonstrates how SQL and Power BI can transform raw website event data into meaningful business insights and actionable recommendations.
